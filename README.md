# Wordwise — Academic Vocabulary Review

A focused, browser-based multiple-choice practice app for **facilitate**, **mitigate**, and **exacerbate**.

## Features

- Six contextual multiple-choice questions
- Immediate feedback with definitions and usage tips
- Progress tracking and final accuracy score
- Responsive design for mobile and desktop
- No build step or dependencies required

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

The app is intentionally dependency-free, so it can also be deployed directly to GitHub Pages, Netlify, or another static host.
